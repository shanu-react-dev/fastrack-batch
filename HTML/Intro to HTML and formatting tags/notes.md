## HTML

_HTML stands for HyperText Markup Language. It is a standard Markup language and used to create structure of the webpages. It helps to add the data or resources like video, text, images, etc inside the webpages._

_it was introduced in 1991 by Tim Berners Lee._

_The current version of HTML is HTML 5.0._

## Tags, elements and attributes

_Any text written enclosed within angular braces known as tags. There are two types of tags._

1. Paired Tags: Here we have opening tag as well as closing tag
2. Unpaired Tags (Self Closing tag): Here we may have either opening or closing tag only one such as meta, hr, br etc. syntax: `<hr>` or `<hr/>`

_Attributes are keywords which provides additional information to the tags or elements. There are two types of attributes._

1. Global Attributes: An attribute which will be applicable for each and every elements
2. Element Specific Attributes: An attribute which will be applicable for only specfic elements.

#### Elements

_Element refers to any content which will be enclosed within opening tag and closing tag._
syntax: `<h1>content</h1>`

## Heading tags

_In HTML if we want to add headings in our webpages then we need to use heading tags there are totally 6 levels of heading h1 to h6. Where h1 refers to the highest priority and h6 is having the least priority._

## Formatting tags

_Formatting tags in HTML is used to format or style the content in the UI without using CSS. Such as making the text bold, italic, highlighting the text etc._
