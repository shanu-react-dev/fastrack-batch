## Lists in HTML

_Lists in HTML is a collection of multiple elements or items either in ordered or unordered way. There are three types of lists in HTML._

1. Ordered Lists: An ordered list is a list whihc will follow an order for the list items or it will give priority to the items. By default its type is numerical, We can change the type of the lists using type attribute so there are 5 types of ordered list such as (1 (default), A, a, I, i). We can create an ordered list using `<ol></ol>` inside this we need to add items using `<li></li>` tag.

2. UnOrdered Lists: This is a collection of items where we don't follow any order for each and every items. By default the type of unordered list is disc, if we want we can change the type of unordered list using type attribute there are four types of unordered list such as (disc (default), circle, square, none)

3. Description lists: This is a collection of items where we can provide a description to each and every items. We can create a description list using dl tag inside this we have `<dt></dt>` tag which holds description term and again we have `<dd></dd>` tag which holds descritpion definitions.
