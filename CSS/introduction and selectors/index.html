Hello CSS

CSS stands for cascading Style Sheets. It is a styling language by which we can add the stylings and positionings to the HTML elements or webpages. Mainly there are three ways by which we can add CSS.

  1. Inline CSS

    2. The Inline CSS is having the highest priority for the CSS to our elements. It can be added inside the opening tag itself using style attribute.

  2. Internal CSS

    3. The internal CSS is used to add css in our webpage. It is having the second priority. Generally it is used for small scale projects. It is used in the same HTML file inside head tag using style tag.

  3. External CSS

    4. External CSS is a way to add the CSS to our webpages efficiently. Using this CSS can save our time and help us to write the code in a cleaner way.
    To use this CSS we need to create one CSS file having extension as .css where we will be writing CSS code or properties. Then we need to link this with HTML file using link tag as follows
    <link rel="stylesheet" href="./style.css" />

It was introduced in 1996 by Håkon Wium Lie. The main purpose was to organize the elements and style it in our viewport.
