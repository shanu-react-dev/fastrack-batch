Selectors in CSS

In CSS to select a specific elements we use selectors. In CSS we have different types of Selectors. There are totally 5 types of Selectors.

Types of Selectors

  1. Simple Selectors
    • ID Selectors
    • Class Selectors
    • Tagname Selectors
    • Grouping Selectors
    • Universal Selectors
  2. Combinator Selectors
    • Descendent Selector
    • Child Selector
    • Adjacent Sibling Selector
    • General Sibling Selector
  3. Attribute Selectors
  4. Pseudo Class Selectors
  5. Pseudo Element Selectors
